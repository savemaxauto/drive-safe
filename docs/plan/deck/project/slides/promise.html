OUR PROMISE TO DRIVERS

A driver’s data is only ever used to help them.

Never used against you

Good Miles only go up. They go only to insurers that use them for discounts.

Sharing is a separate choice

The freshener, Drive Mode and partner offers work without sharing anything.

Safer drives pay off

Phone-free streaks earn points for refills, car washes and gas.

We can promise this because we don’t sell insurance or set rates.

This is why a driver would say yes to us after saying no to an insurer. We meet them before they're shopping for a policy, and we don't set their rate. So we can put it in writing. Sharing is optional, safe driving earns rewards, and we only share a driver's Good Miles, the miles they drive with the phone down, with insurers that agree to use them for discounts, never to raise a price. We don't track speed or braking at all. Jerry already does something similar and only shares a score when it lowers the premium.
